===============================================================================
СИСТЕМА УПРАВЛЕНИЯ ПЕКАРНЕЙ-КОФЕЙНЕЙ
Bakery Cafe Management System
Версия: 1.0
===============================================================================

ОПИСАНИЕ:
---------
Программа для управления бизнесом пекарни-кофейни с одним продавцом.
Система имеет собственное реальное ядро (Kernel.vbs), без которого 
невозможен запуск программы, так как ядро содержит всю бизнес-логику.

ТРЕБОВАНИЯ:
-----------
- Операционная система: Windows 7/8/10/11
- Windows Script Host 5.6 или выше (встроен в Windows)
- Разрешение экрана: 1024x768 или выше

СТРУКТУРА ПАПКИ:
----------------
BakeryCafeSystem/
├── Kernel.vbs          - ЯДРО СИСТЕМЫ (критически важный файл!)
├── MainApp.vbs         - Главное приложение (интерфейс)
├── Install.bat         - Скрипт установки
├── RunApp.bat          - Скрипт запуска программы
└── README.txt          - Этот файл

УСТАНОВКА:
----------
1. Скопируйте папку BakeryCafeSystem в любое место на компьютере
2. Запустите файл Install.bat от имени администратора (опционально)
3. Установка создаст ярлык на рабочем столе

ЗАПУСК ПРОГРАММЫ:
-----------------
Вариант 1: Дважды кликните по ярлыку "Пекарня-Кофейня" на рабочем столе
Вариант 2: Запустите файл RunApp.bat

ФУНКЦИОНАЛЬНОСТЬ:
-----------------
• Управление меню продуктов (кофе, выпечка, десерты, еда)
• Создание и обработка заказов клиентов
• Добавление товаров в заказ
• Завершение заказов с подсчётом общей суммы
• Отчёты о продажах (количество продаж, общая выручка)
• Контроль состояния склада (inventory)
• Поиск продуктов по названию
• Информация о системе и текущей смене

ЯДРО СИСТЕМЫ (Kernel.vbs):
--------------------------
Ядро является критически важным компонентом системы. Оно содержит:
- Класс BakeryCafeKernel со всей бизнес-логикой
- Управление продуктами и ценами
- Обработку заказов
- Учёт продаж
- Управление inventory
- Функции поиска и отчётности

Без файла Kernel.vbs программа НЕ ЗАПУСТИТСЯ!

ПЕРВЫЙ ЗАПУСК:
--------------
1. При первом запуске программа запросит:
   - Название вашей пекарни-кофейни
   - Имя продавца
   
2. После ввода данных система инициализирует ядро
3. Откроется главное меню программы

ГЛАВНОЕ МЕНЮ:
-------------
1. Показать меню продуктов - просмотр всех доступных товаров
2. Создать новый заказ - начало оформления заказа клиента
3. Просмотреть активные заказы - информация о текущих заказах
4. Завершить заказ - финализация заказа и запись в историю продаж
5. Отчёт о продажах - статистика по всем завершённым заказам
6. Состояние склада - просмотр inventory
7. Поиск продукта - поиск товара по названию
8. Информация о системе - данные о магазине и продавце
0. Выход - завершение работы программы

ПРИМЕР РАБОТЫ С ЗАКАЗОМ:
------------------------
1. Выберите пункт 2 "Создать новый заказ"
2. Система создаст заказ с уникальным ID (например, ORD00001)
3. Введите ID продукта (например, P002 для Капучино)
4. Введите количество (например, 2)
5. Добавьте другие товары при необходимости
6. Подтвердите завершение заказа
7. Система запишет продажу в историю

ПРИМЕЧАНИЯ:
-----------
- Все данные хранятся в оперативной памяти до закрытия программы
- Для постоянного хранения данных требуется модификация ядра
- Ядро использует singleton-паттерн для обеспечения целостности данных
- Система работает только с одним продавцом одновременно

ТЕХНИЧЕСКАЯ ИНФОРМАЦИЯ:
-----------------------
- Язык программирования: VBScript
- Интерфейс: GUI (MsgBox, InputBox)
- Хранение данных: Scripting.Dictionary
- Паттерн ядра: Singleton

ПОДДЕРЖКА:
----------
При возникновении проблем убедитесь, что:
1. Все файлы находятся в одной папке
2. Файл Kernel.vbs присутствует и не повреждён
3. Windows Script Host включён в системе
4. У вас есть права на выполнение .bat и .vbs файлов

ЛИЦЕНЗИЯ:
---------
Программа предоставлена "как есть" для использования в бизнес-целях.

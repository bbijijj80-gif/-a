# СИСТЕМА УПРАВЛЕНИЯ ПЕКАРНЕЙ-КОФЕЙНЕЙ

## Описание
Программа для автоматизации работы пекарни-кофейни с одним продавцом.

## Архитектура
Система состоит из двух основных компонентов:

### 1. Ядро (Core) - C#
- **Файл:** `Core/BusinessKernel.cs`
- **Назначение:** Вся бизнес-логика приложения
- **Важно:** Без ядра приложение НЕ МОЖЕТ быть запущено
- Содержит:
  - Управление продуктами (кофе, выпечка)
  - Обработка заказов
  - Генерация отчётов
  - Сохранение данных

### 2. Приложение (App) - C++
- **Файл:** `App/main.cpp`
- **Назначение:** Пользовательский интерфейс для продавца
- **Функции:**
  - Просмотр ассортимента
  - Создание заказов
  - Просмотр отчётов
  - Сохранение данных

## Структура проекта
```
BakeryCoffeeSystem/
├── Core/                    # Ядро на C#
│   ├── BusinessKernel.cs    # Основная логика
│   ├── KernelLoader.cs      # Загрузчик ядра
│   ├── KernelExport.cs      # Экспорт функций для C++
│   └── Core.csproj          # Проект .NET
├── App/                     # Приложение на C++
│   └── main.cpp             # Главный файл
├── Installer/               # Установщик
│   └── build.bat            # Скрипт сборки
└── README.md                # Этот файл
```

## Требования для сборки

### Обязательные:
- **.NET SDK 6.0** или выше - [скачать](https://dotnet.microsoft.com/download)
- **Windows** (для запуска собранного приложения)

### Опционально (для полной сборки):
- **Visual Studio 2019/2022** с компонентом "Разработка на C++"
- ИЛИ **Visual Studio Build Tools**

## Инструкция по сборке

### Шаг 1: Запустите скрипт сборки
```batch
cd Installer
build.bat
```

### Шаг 2: Дождитесь завершения
Скрипт автоматически:
1. Проверит наличие .NET SDK
2. Проверит наличие компилятора C++
3. Скомпилирует ядро на C#
4. Скомпилирует приложение на C++ (если есть компилятор)
5. Создаст папку `Build` со всеми необходимыми файлами

### Шаг 3: Запуск программы
После сборки перейдите в папку `Build` и запустите:
```batch
START.bat
```

ИЛИ напрямую:
```batch
App\BakeryCoffeeApp.exe
```

## Важно!

⚠️ **ЯДРО ЯВЛЯЕТСЯ ОБЯЗАТЕЛЬНЫМ КОМПОНЕНТОМ**

Без файла `BakeryCoffeeCore.dll` приложение не запустится.
При запуске происходит проверка:
1. Наличие DLL файла ядра
2. Успешная загрузка ядра
3. Инициализация ядра
4. Проверка статуса ядра

Если любой из этих шагов не пройден - приложение немедленно завершается.

## Функционал программы

### Для продавца:
1. **Просмотр ассортимента** - все товары с ценами
2. **Создание заказа** - выбор товаров, подсчёт суммы
3. **Отчёт за день** - статистика продаж
4. **Сохранение данных** - экспорт в файл

### Товары в системе:
**Кофе:**
- Эспрессо - 150 руб.
- Капучино - 200 руб.
- Латте - 220 руб.

**Выпечка:**
- Круассан - 120 руб.
- Булочка с корицей - 100 руб.
- Чизкейк - 250 руб.

## Распространение

Для передачи программы клиенту:
1. Соберите проект через `build.bat`
2. Скопируйте папку `Build` целиком
3. Передайте клиенту
4. Клиент должен установить [.NET 6 Runtime](https://dotnet.microsoft.com/download/dotnet/6.0/runtime)

## Техническая информация

### Ядро (C#)
- Паттерн Singleton для единственного экземпляра
- Проверка инициализации перед каждым вызовом
- Экспорт функций через DllExport для вызова из C++

### Приложение (C++)
- Загрузка ядра через LoadLibrary
- Получение функций через GetProcAddress
- Обязательная проверка статуса ядра перед работой

### Безопасность
- Ядро нельзя обойти - все операции проходят через него
- При удалении DLL приложение не работает
- Все данные обрабатываются централизованно

## Поддержка

При возникновении проблем:
1. Убедитесь, что установлен .NET 6.0 Runtime
2. Проверьте наличие всех файлов в папке App
3. Убедитесь, что BakeryCoffeeCore.dll не повреждён

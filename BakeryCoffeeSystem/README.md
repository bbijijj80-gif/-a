# Система управления Пекарней-Кофейней

## Описание
Программа для управления небольшой пекарней-кофейней с одним продавцом.
Состоит из двух частей:
- **Ядро (C#)** - вся бизнес-логика, без него запуск невозможен
- **Приложение (C++)** - пользовательский интерфейс

## Структура проекта
```
BakeryCoffeeSystem/
├── Core/                      # Ядро на C#
│   ├── BakeryCoffeeCore.cs    # Исходный код ядра
│   └── BakeryCoffeeCore.csproj # Проект ядра
├── App/                       # Приложение на C++
│   └── main.cpp               # Исходный код приложения
├── build.bat                  # Скрипт сборки
└── build/                     # Папка с готовым приложением (создается после сборки)
    ├── BakeryCoffeeApp.exe    # Основной исполняемый файл
    ├── Core/
    │   └── BakeryCoffeeCore.dll  # Ядро системы (обязательно!)
    └── data/                  # Данные (создается при первом запуске)
```

## Требования для сборки
1. **.NET 6.0 SDK** - скачать с https://dotnet.microsoft.com/download
2. **MinGW-w64 с g++** - скачать с https://www.mingw-w64.org/ или использовать MSYS2

## Сборка
1. Запустите `build.bat`
2. Дождитесь завершения сборки
3. Готовая программа будет в папке `build/`

**Важно:** После выполнения скрипта окно не закроется - можно посмотреть логи и нажать любую клавишу для закрытия.

## Запуск программы
1. Перейдите в папку `build/`
2. Запустите `BakeryCoffeeApp.exe`

**Критически важно:** Файл `Core/BakeryCoffeeCore.dll` должен находиться рядом с exe-файлом!
Без этого файла программа не запустится - ядро содержит всю бизнес-логику.

## Возможности программы
- Просмотр списка товаров (кофе, выпечка, десерты)
- Создание заказов
- Добавление товаров в заказ
- Подсчет суммы заказа
- Просмотр выручки за день
- Автоматическое управление складом

## Как это работает
1. При запуске приложение загружает ядро `BakeryCoffeeCore.dll`
2. Ядро инициализируется и создает файлы данных в папке `data/`
3. Все операции (заказы, товары, отчеты) выполняются через ядро
4. Без ядра приложение немедленно завершает работу

## Файлы данных
После первого запуска в папке `data/` создаются:
- `products.json` - список товаров и их количество
- `orders.json` - история заказов
